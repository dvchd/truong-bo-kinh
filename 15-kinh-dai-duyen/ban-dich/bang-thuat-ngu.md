## Bảng thuật ngữ

| Pali | Tiếng Việt | Ghi chú |
|---|---|---|
| mahānidāna | **đại duyên** | tên bài |
| paṭiccasamuppāda | **duyên khởi** | |
| nāmarūpa | **danh và sắc** | danh = thọ, tưởng, tư, xúc, tác ý; sắc = bốn đại và sắc do bốn đại tạo |
| viññāṇa | **thức** | sáu loại: nhãn, nhĩ, tỷ, thiệt, thân, ý |
| saḷāyatana | **sáu xứ** | |
| phassa | **xúc** | sáu loại xúc |
| vedanā | **thọ** | sáu loại thọ |
| taṇhā | **ái** | sáu loại ái |
| upādāna | **thủ** (bám víu) | |
| bhava | **hữu** | |
| jāti | **sinh** | |
| jarāmaraṇa | **già chết** | |
| attā | **tự ngã** | |

### Xưng hô

| Ai → ai | Tiếng Việt |
|---|---|
| Đức Thế Tôn → Ānanda | "này Ānanda" |
| Ānanda → Đức Thế Tôn | "bạch Thế Tôn"; tự xưng "con" |
| người kể → Ānanda | "Tôn giả Ānanda" |
| người kể → Đức Thế Tôn | "Đức Thế Tôn", đại từ **"Ngài"** |

### Chỗ dễ dịch sai

| Chỗ | Dịch đúng |
|---|---|
| `Chớ nói vậy, này Ānanda` | giữ đúng giọng **quở**, không làm nhẹ thành "không hẳn vậy" |
| chuỗi duyên khởi ở bài này | **không bắt đầu từ vô minh** — bắt đầu từ danh và sắc / thức |
| `attā` | **tự ngã** (không phải "linh hồn"; `jīva` mới là linh hồn) |
| `khandha` | **uẩn** |
