## Bảng thuật ngữ

Bài này có ba nhóm từ khó: tưởng, tự ngã và các tầng định; ba loại thân; và bộ từ phân loại giáo
pháp.

### Tưởng và các tầng định

| Pali | Tiếng Việt | Ghi chú |
|---|---|---|
| saññā | **tưởng** | không dịch "cảm giác" hay "tri giác" |
| saññānirodha | **sự diệt của tưởng** | |
| abhisaññānirodha | **sự diệt của tưởng** | tiểu từ `abhi-` không đổi nghĩa; xem chú thích 6.4 |
| saññāsamāpatti | **định tưởng** | |
| saññāvihāra | **trú xứ của tưởng** | |
| sakasaññī | **tự làm chủ tưởng của mình** | |
| saññāgga | **đỉnh cao của tưởng** | tầng định phi tưởng phi phi tưởng |
| ākāsānañcāyatana | **tầng định không vô biên xứ** | |
| viññāṇañcāyatana | **tầng định thức vô biên xứ** | |
| ākiñcaññāyatana | **tầng định vô sở hữu xứ** | |
| nevasaññānāsaññāyatana | **tầng định phi tưởng phi phi tưởng** | |
| nirodha | **sự diệt** | |
| sikkhā | **sự tu tập** | |
| ñāṇa | **hiểu biết** | tách khỏi `paññā` = tuệ |

### Tự ngã và ba loại thân

| Pali | Tiếng Việt | Ghi chú |
|---|---|---|
| attā | **tự ngã** | |
| attapaṭilābha | **sự hóa sinh** (nghĩa đen: sự đạt được tự ngã) | chú giải: `attā` đây là `attabhāva`, tức dạng sống |
| oḷāriko attapaṭilābho | **thân do vật chất tạo** | sắc, bốn đại, nuôi bằng thức ăn cục |
| manomayo attapaṭilābho | **thân do tâm tạo** | sắc, đủ căn, do tâm tạo |
| arūpo attapaṭilābho | **thân phi sắc** | do tưởng tạo (`saññāmayo`) |
| kabaḷīkārāhāra | **thức ăn cục** | |
| dibbarūpa | **sắc trời** | |

### Nhân vật và xưng hô

| Ai → ai | Tiếng Việt |
|---|---|
| Poṭṭhapāda → Đức Thế Tôn | "bạch Thế Tôn" đầu câu, "thưa Ngài" khi chen vào; xưng "tôi" hoặc "con" |
| Đức Thế Tôn → Poṭṭhapāda | "này Poṭṭhapāda", đại từ **"ông"** |
| Citta Hatthisāriputta → Đức Thế Tôn | "bạch Thế Tôn", "con" |
| Đức Thế Tôn → Citta | "này Citta" |
| người kể → Đức Thế Tôn | "Đức Thế Tôn", đại từ **"Ngài"** |

### Chỗ dễ dịch sai

| Chỗ | Dịch đúng | Dịch sai thường gặp |
|---|---|---|
| `saññā` | **tưởng** | "cảm giác" — làm hỏng cả lập luận về diệt tưởng |
| `attapaṭilābha` | **sự hóa sinh** | "sự đạt được tự ngã" — nghĩa đen, nhưng tối nghĩa trong tiếng Việt |
| `ekaṁsika` | **được nói dứt khoát** | "nhất định" — mất nghĩa phân loại giáo pháp |
| `attā` trong 21.x | **tự ngã** | "linh hồn" — chỉ dùng "linh hồn" cho `jīva` |
| `jīva` / `sarīra` | **linh hồn / thân xác** | lẫn với `attā` |
| `abhisaññānirodha` | **sự diệt của tưởng** | "diệt tưởng hoàn toàn" — `abhi-` chỉ là tiểu từ |
