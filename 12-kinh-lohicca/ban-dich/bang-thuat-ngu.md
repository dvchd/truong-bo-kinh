## Bảng thuật ngữ

| Pali | Tiếng Việt | Ghi chú |
|---|---|---|
| lohicca | Lohicca | bà-la-môn ở Sālavatikā |
| kalyāṇadhamma | **pháp lành** | trục của mục 1 |
| anussāveti / anussāvetabbaṁ | **nói lại cho người khác** | cũng là trục của mục 1 |
| pāpakaṁ diṭṭhigataṁ | **tà kiến xấu ác** | |
| diṭṭhi | **tà kiến / chánh kiến** | |
| satthā | **bậc thầy**, **vị thầy** | |
| anusāsati | **giáo huấn**, **dạy bảo** | |
| sāmañña | **đời sống sa-môn**, **hạnh sa-môn** | |
| sāvaka | **đệ tử** | |
| sakkāya | **thân kiến** (trong ngữ cảnh này) | |
| gihī / agārika | **người tại gia** | |
| sīla / samādhi / paññā | **giới / định / tuệ** | |
| abhiññā | **thắng trí** | |
| āsavānaṁ khaya | **đoạn tận lậu hoặc** | |
| lābhasakkāra | **lợi lộc và danh vọng** | |

### Ba hạng thầy

| Hạng | Nội dung |
|---|---|
| 1 | chưa đạt mục đích đời sống sa-môn mà vẫn nhận đệ tử và thuyết pháp |
| 2 | không nghe, không cầu, không hiểu mà vẫn thuyết pháp |
| 3 | sống đời xuất gia mà vẫn bị lợi lộc và danh vọng làm hư |

### Xưng hô

| Ai → ai | Tiếng Việt |
|---|---|
| Lohicca → Đức Thế Tôn | "thưa ngài Gotama" (trước khi quy y), "bạch Thế Tôn" (sau) |
| Đức Thế Tôn → Lohicca | "này Lohicca" |
| người kể → Đức Thế Tôn | "Đức Thế Tôn", đại từ **"Ngài"** |
