# Muc 8 — Description of Individuals  (5 đoạn)

## dn28:8.0
- **PLI**: 1.6. Puggalapaṇṇattidesanā
- **EN**: 1.6. Description of Individuals

## dn28:8.1  `ms8D_310, msdiv150, pts-cs8`
- **PLI**: Aparaṁ pana, bhante, etadānuttariyaṁ, yathā bhagavā dhammaṁ deseti puggalapaṇṇattīsu.
- **EN**: And moreover, sir, how the Buddha teaches the description of individuals is unsurpassable.

## dn28:8.2
- **PLI**: Sattime, bhante, puggalā.
- **EN**: There are these seven individuals.

## dn28:8.3
- **PLI**: Ubhatobhāgavimutto paññāvimutto kāyasakkhi diṭṭhippatto saddhāvimutto dhammānusārī saddhānusārī.
- **EN**: One freed both ways, one freed by wisdom, a direct witness, one attained to view, one freed by faith, a follower of teachings, a follower by faith.
- **NOTE**: As at <a href='https://suttacentral.net/an7.14/en/sujato#1.3'>AN 7.14:1.3</a>.

## dn28:8.4
- **PLI**: Etadānuttariyaṁ, bhante, puggalapaṇṇattīsu.
- **EN**: This is unsurpassable when it comes to the description of individuals.
